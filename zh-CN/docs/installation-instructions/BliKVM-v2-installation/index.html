BliKVM v2

1. 拆包并取出设备​

"产品清单"

2. 安装主设备​

"安装 CM4 和 4 个六角隔柱（本文以 CM4 lite 为例，使用 Micro SD 卡中的镜像，CM4 eMMC 用户需自行烧录镜像。）在 CM4 顶部贴上导热片，并撕掉导热片的保护膜。"

主设备安装完成。

3. 连接 USB 和 ATX​

"本文使用的主板为华硕 H520M-E，不同主板的接口定义可能不同，请参考您的主板手册。"

4. 连接 OLED​

"您收到的 OLED 没有安装支架，请参考图片进行安装。此外，OLED 支架由亚克力材料制成，需撕掉表面保护膜后使用。"

以上是安装步骤，未撕膜效果如下。实际使用时，请撕掉保护膜。

5. 连接 HDMI 线​

"使用 HDMI 线将电脑的 HDMI 输出端口直接连接到产品的 HDMI IN 端口。HDMI 直通 EDID 模拟器不是必需的！如果您的电脑未输出正确的 HDMI 格式，请将 HDMI 直通 EDID 模拟器插入电脑的 HDMI 输出端口。这可以让您在电脑上配置固定的 HDMI 输出格式。"

6. 连接网线​

"千兆以太网端口标准：IEEE 802.3af PoE 输入电压：37v-57v。"

"使用 PoE 供电时，无需连接 PWR-IN 端口。"

7. 连接 PWR-IN​

"未使用 PoE 供电时，将 PWR-IN 端口连接到标准 5V/3A USB 电源。"

8. 测试​

"OLED 屏幕显示设备 IP 和其他信息。"

在浏览器中访问 IP 地址。测试通过后，将产品安装到电脑机箱中。

9. 将产品安装到电脑机箱中​

"断开电源和布线，将产品安装到主板上，安装完成后重新连接电缆。不同批次收到的 ATX 电缆颜色可能不同，请直接参考针脚定义进行连接。"

享受使用吧！
