故障排查、日志与监控

入口：设置 → 高级与诊断 → 故障排查。需要相应管理权限。

Demo 截图：仅展示界面和模拟状态，未执行设备配置、摄像头授权或通道切换。点击可查看完整原图。

收集问题信息​

  1. 记录设备型号、应用和系统版本、浏览器、所选模式及复现步骤。
  2. 区分局域网和远程结果，再确定故障属于供电、HDMI、USB、网络、认证还是升级任务。
  3. 按需调整日志级别并应用，复现一次后查看实时日志或下载诊断信息。
  4. 完成后恢复正常日志级别。页面说明重启后会恢复警告级别；不要长期保留调试级日志。

诊断包可能包含配置、日志、地址和设备信息。分享前审查敏感内容，不要直接上传完整私密配置或令牌。下载成功只说明导出完成，不能证明故障已经修复。

视频与系统监控​

  • 视频细节见 HDMI 分析与延迟。
  • 高级菜单中的 Prometheus 可按需开启并查看状态；采集方需符合当前接口认证和访问权限，不应把监控端口默认暴露公网。
  • 请求返回无权限时先核对角色；能力缺失时检查系统组件，避免反复重装驱动。
