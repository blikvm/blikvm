BliKVM 功能清单

按场景查找功能、适用条件和操作指南。

实际可用功能取决于硬件型号、系统和 App 版本、账号权限，以及浏览器或配件支持。 查看各型号手册

远程控制台画面、音频与摄像头装机、恢复与电源网络与远程访问账号与安全开发与自动化升级与维护

远程控制台

  • 浏览器远程控制

    通过 HDMI 查看被控电脑，包括 BIOS 和启动画面。

  • USB 键鼠

    通过 USB HID 操作被控电脑，支持屏幕键盘和键鼠转发。

  • 鼠标模式与防休眠

    按操作场景选择鼠标模式，或使用鼠标微动保持活动。

  • 组合键与宏

    发送快捷键或运行配置好的按键序列。

  • 文本输入与 OCR

    通过模拟键盘输入文本，或识别画面中选定区域的文字。

  • 界面偏好

    调整控制台主题、语言和界面偏好。

画面、音频与摄像头

  • HDMI 视频与串流

    按设备和浏览器支持选择 H.264 / H.265 WebRTC 或 MJPEG。

  • 截图与录制

    保存远程画面截图，或使用浏览器支持的录制功能。

  • EDID

    在支持的设备上管理 HDMI 输入向电脑声明的显示模式。

  • HDMI 环出

    带 HDMI 输出的硬件可连接本地显示器，软件控制取决于平台。

  • 远程音频与模拟麦克风

    在浏览器收听被控电脑声音，或将管理端麦克风转发成被控端的 USB 麦克风。

  • 第二路 USB 摄像头

    通过 BliKVM 的 USB 主机口接入兼容摄像头，查看独立于 HDMI 的画面。

  • UVC 摄像头转发

    将管理端摄像头转发为被控电脑识别的 USB 摄像头，需要相应 USB 功能和浏览器权限。

  • HDMI 分析与延迟检查

    查看输入信号信息，排查采集与串流链路。

装机、恢复与电源

  • 虚拟光驱与闪存盘

    挂载 ISO 启动安装或救援环境，或用虚拟闪存盘传文件。需要 USB 数据连接和存储功能。

  • USB 功能配置

    按设备支持启用键鼠、存储、麦克风和摄像头等 USB 类。

  • ATX 电源和复位

    通过兼容的 ATX 控制板和主板接线操作电源、复位并查看电源状态。

  • 网络唤醒

    发送唤醒包。被控电脑的固件、网卡和网络需支持。

  • 串口终端

    在配置了兼容串口设备和接线的情况下打开终端。

  • 多机切换

    一台 BliKVM 搭配 BliSwitch v1 或 v2，可在最多 4 台或 8 台电脑之间切换 HDMI 和 USB。v2 接好 ATX 后支持逐台电源控制。

网络与远程访问

  • 本地网络与固定 IP

    查看地址和配置固定 IP、网关与 DNS。

  • Wi-Fi 与 v4 面板配网

    在有无线硬件和驱动的设备上配网。v4 面板配网需要相应系统镜像。

  • VPN 与组网

    按设备和部署条件使用 WireGuard、Tailscale 或 ZeroTier。

  • 反向代理、隧道与云接入

    按部署选择远程入口，并分别验证登录、WebRTC 媒体链路和操作权限。

  • 动态 DNS

    使用 DDNS 更新域名记录，适合公网地址会变化的部署。

  • VNC 服务

    在支持的配置上用兼容的 VNC 客户端查看画面和操作键鼠。

账号与安全

  • 账号、角色与权限

    按管理员、操作员和查看者分配权限，可单独授权电源、媒体和输入等操作。

  • 双因素认证

    在账号设置中配置验证器应用。

  • HTTPS 与证书

    管理设备 HTTPS 证书，为浏览器和 API 客户端配置证书信任。

  • IP 访问规则

    按来源地址限制访问。

开发与自动化

  • REST API 与 OpenAPI

    查阅认证、请求参数和响应结构，集成设备操作。

  • 键盘 API 与 Keycode

    查阅按键编码，按用途选择单键、组合键或文本输入接口。

  • 系统脚本

    在支持的系统和 App 上管理手动任务、开机任务及常驻服务。脚本运行在 BliKVM 上。

  • Prometheus 指标

    在诊断设置中启用监控指标，按 API 认证和权限配置采集端。

升级与维护

  • 首次烧录与重装

    按型号选择系统镜像，按手册烧录到相应的启动介质。

  • App 更新与 A/B 系统更新

    分别使用匹配平台的 App 包或 A/B 系统更新包。A/B 更新还需满足设备启动条件。

  • 设备信息、日志与诊断

    查看系统与 App 版本，查看实时日志或导出诊断资料。

  • SSH 管理

    按设备系统与账号设置使用 SSH 进行维护。

  • 恢复出厂设置

    按设备手册清除配置并重新初始化设备。

  • 设备屏幕与前面板

    在支持的型号上查看本地状态。v4 的面板操作见设备指南。
