BliKVM feature list

Find features, their requirements, and setup guides by task.

Availability depends on the hardware model, system and app versions, account permissions, and browser or accessory support. See model manuals

Remote consoleVideo, audio, and camerasInstallation, recovery, and powerNetworking and remote accessAccounts and securityDevelopment and automationUpdates and maintenance

Remote console

  • Browser remote control

    View the target over HDMI, including BIOS and boot screens.

  • USB keyboard and mouse

    Control the target through USB HID using keyboard and mouse forwarding or the on-screen keyboard.

  • Mouse modes and jiggler

    Choose a mouse mode or use the mouse jiggler to keep the target active.

  • Shortcuts and macros

    Send shortcuts or run a configured key sequence.

  • Text input and OCR

    Type text through keyboard emulation or recognize text in a selected region of the screen.

  • Interface preferences

    Adjust console theme, language, and interface preferences.

Video, audio, and cameras

  • HDMI video and streaming

    Choose H.264 or H.265 over WebRTC, or MJPEG, where supported by the device and browser.

  • Screenshots and recording

    Save a remote frame or record using supported browser functionality.

  • EDID

    Manage the display modes advertised to the computer on supported devices.

  • HDMI passthrough

    Connect a local monitor on hardware with HDMI output. Software controls vary by platform.

  • Remote audio and microphone emulation

    Listen to target audio or forward the management microphone as a USB microphone on the target.

  • Secondary USB camera

    Connect a compatible camera to the BliKVM USB host port for a feed separate from HDMI.

  • UVC camera forwarding

    Present the management camera as a USB camera on the target, with supported USB functions and browser permissions.

  • HDMI analysis and latency

    Inspect input signal information and troubleshoot capture and streaming.

Installation, recovery, and power

  • Virtual CD/DVD and flash drive

    Boot an installer or rescue image from ISO, or transfer files using a virtual flash drive. Requires USB data and storage support.

  • USB function configuration

    Enable supported USB classes such as keyboard, mouse, storage, microphone, and camera.

  • ATX power and reset

    Use a compatible ATX board and motherboard wiring for power, reset, and status.

  • Wake-on-LAN

    Send a wake packet to a target with compatible firmware, network adapter, and network.

  • Serial terminal

    Open a terminal with a compatible serial device and wiring.

  • Multi-computer switching

    Switch HDMI and USB between up to 4 computers with BliSwitch v1 or 8 with v2. The v2 supports per-host power control with ATX wiring.

Networking and remote access

  • LAN and static IP

    Inspect addresses and configure a static IP, gateway, and DNS.

  • Wi-Fi and v4 front-panel setup

    Connect supported wireless hardware. Front-panel setup on v4 requires a compatible system image.

  • VPN and overlay networking

    Use WireGuard, Tailscale, or ZeroTier as supported by your device and deployment.

  • Proxy, tunnel, and cloud access

    Choose a remote entry point and verify sign-in, the WebRTC media path, and permissions separately.

  • Dynamic DNS

    Update DNS records when the deployment’s public address changes.

  • VNC service

    View video and send input with a compatible VNC client on supported configurations.

Accounts and security

  • Accounts, roles, and permissions

    Assign administrator, operator, or viewer roles and grant specific actions such as power, media, and input.

  • Two-factor authentication

    Set up an authenticator app in account settings.

  • HTTPS and certificates

    Manage the device’s HTTPS certificate and configure trust for browsers and API clients.

  • IP access rules

    Restrict access by source address.

Development and automation

  • REST API and OpenAPI

    Use the authentication, request, and response reference to integrate device operations.

  • Keyboard API and keycodes

    Look up keycodes and choose endpoints for single keys, combinations, or text input.

  • System scripts

    Manage manual tasks, startup tasks, and resident services with a compatible system and app. Scripts run on BliKVM.

  • Prometheus metrics

    Enable metrics in diagnostics and configure the collector with the required API authentication and permissions.

Updates and maintenance

  • First flash and reinstall

    Choose an image for your model and follow the guide to flash the appropriate boot media.

  • App updates and A/B system updates

    Use the matching app package or A/B system bundle. A/B updates also require compatible boot firmware and system support.

  • Device information, logs, and diagnostics

    Check system and app versions, view live logs, or export diagnostics.

  • SSH administration

    Maintain the device over SSH according to system and account settings.

  • Factory reset

    Clear configuration and reinitialize the device following the guide.

  • Device display and front panel

    View local status on supported models. See the v4 guide for front-panel controls.
