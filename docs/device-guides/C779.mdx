# C779 capture module

## Hardware specifications

- HDMI input up to 1080p50 on compatible Raspberry Pi systems, limited by CSI-2 lanes.
- Toshiba TC358743XBG HDMI-to-CSI-2 bridge.
- Two CSI-2 data lanes and clock.
- 15-pin FPC connector, 1.0 mm pitch.
- 35 × 50 mm, four M2.5 mounts, 3.3V, 10g.

## Dimensions

Four 2.75 mm mounting holes accept M2.5 screws.

![C779 dimensions](/assets/images/hdmi-csi-i2s/c779-size.png)

## Wiring and verification

Power off before connecting a matching ribbon and check contact direction. Equal pin counts do not guarantee cable compatibility.
