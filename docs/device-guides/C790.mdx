# C790 capture module

## Hardware specifications

- HDMI input up to 1080p60 on a compatible Raspberry Pi platform.
- Toshiba TC358743XBG HDMI-to-CSI-2 bridge.
- Four CSI-2 data lanes and clock.
- Front: 15-pin FPC, 1.0 mm pitch; rear: 22-pin FPC, 0.5 mm pitch.
- 30 × 45 mm, four M2.5 mounts, 3.3V, 10g.

:::warning CSI lane limits
Pi 4B is limited to 1080p50 by its CSI-2 lane count. CM4 supports 1080p60; use the compatible four-lane connection when that input is required.
:::
