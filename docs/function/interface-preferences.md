# Interface preferences

Open **Settings → Interface Preferences**. These mostly affect the current browser experience, rather than the controlled OS, USB functions or other users.

- **Language:** changes the web language, not the computer's keyboard layout.
- **Appearance:** choose the theme and other offered display preferences.
- **Input method:** automatic, mouse or touch. Automatic uses touch capability rather than screen width alone; wide screens retain the desktop layout.
- **Page title:** device branding / title configuration may require administrator permission, so not every preference is browser-local.
- **Alerts:** adjust interface notifications; hiding an alert does not fix its cause.

Cursor appearance is under **Keyboard, Mouse & USB → Cursor Style**. Absolute / relative behavior relates to USB input; see [Mouse modes](../peripheral-devices/keyboard-mouse/mouse.md).

Language, theme and touch preferences can change with browser, site origin or storage cleanup. A different device address or port creates a different storage origin. Factory reset does not clear preferences on the management computer.
