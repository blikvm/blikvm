# Paste and text extraction

## Type through keyboard emulation

Choose **Paste** in the toolbar, enter text and send it as directed. First test a short passage in an editor, checking keyboard layout and line breaks before real commands.

Text arrives as keyboard events, not clipboard sharing or file upload. Layout, input method, focus and supported character conversion affect results; arbitrary Unicode input is not guaranteed. Long text takes time to type. Keep focus and observe task state.

## Extract text from the picture

Choose **Text Extraction**, select the recognition language, drag an area and review the result. OCR processes pixels rather than reading files or the computer's clipboard.

First use may load language resources and fail if resources or network are unavailable. Scaling, blur, small fonts and mixed languages reduce accuracy. Check paths, numbers, command punctuation and key characters carefully.

## Limitations

Clipboard access may need trusted HTTPS, browser permission or manual paste. Keep sensitive content out of shared macros, screenshots and logs. Sending requires input permission. Recognized text does not prove a command executed or a file changed.
