# Mouse jiggler

Open **Settings → Keyboard, Mouse & USB → Mouse Jiggler** with input-automation permission.

When enabled, the device sends periodic small mouse movements to reduce inactivity. The current interface switches a fixed interval; it does not require editing `jigglerTimeDiff` or restarting old services.

## Use

1. Verify mouse input and USB connectivity.
2. Enable the jiggler and confirm the setting updates.
3. With no other input, observe small movements on the computer.
4. Disable after use and confirm movement stops.

This does not change OS power policy or guarantee avoidance of every lock or sleep rule. Coordinate on shared computers so automatic motion does not interfere. Resolve missing permission or disabled USB mouse functions first.
