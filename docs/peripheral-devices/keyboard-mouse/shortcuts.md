# On-screen keyboard and macros

The toolbar provides **Keyboard** and **Keyboard Macros**. Your browser or local OS may intercept shortcuts first; the on-screen keyboard can send those combinations.

## Send combinations

1. Put the controlled computer in the intended program or screen.
2. Open the keyboard and select modifiers and keys.
3. Observe the response and ensure modifiers are released before more input.

Confirm window focus before sending shutdown, deletion or firmware-setting keys.

## Create a macro

1. Open macros, add one and name it.
2. Combine keys, text and waits using the interface. Allow time for programs to load.
3. Save and test a short harmless sequence first.
4. Use import / export for reuse and inspect imported content before running it.

Macros send input in order; they do not understand computer state or verify successful installation. Password macros and exports contain sensitive text and should not be shared. Macros require input-automation permission; ordinary typing requires input-control permission.

For long text, non-ASCII characters and OCR limitations see [Paste and text extraction](../paste-ocr.md). Current macros do not require editing old shortcut JSON files.
