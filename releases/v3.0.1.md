## English

### What changed

- **Keyboard/mouse status:** readiness is reported independently. Dual mouse mode shows absolute and relative path status, including partial readiness. Disabled functions do not degrade overall connection status; stale readiness is cleared when the status connection is lost.
- **Update discovery:** immutable hardware/capture identifiers help locate matching releases. App and system updates are checked separately, with download links; checking does not automatically install updates.
- **Package consistency:** all platforms use pinned backend/frontend main-source commits. Each factory image and system bundle contains the same signed App payload as its matching standalone App package. Standalone build source/version locks are recorded for reproducibility.

### Upgrade instructions

| Your situation | Package and action |
| --- | --- |
| New installation or reinstall | Download the matching `.img.xz`, decompress to `.img`, then flash. Flashing overwrites the target medium's data. |
| Existing compatible A/B installation | Install the matching `.raucb` in System Update. After reboot, the system activates its included App 3.0.1. |
| App-only update | Install the matching `-app-3.0.1.tar.gz` in App Update. This does not replace the OS. The signed minimum OS requirement remains 0.1.1; this is a compatibility floor, not the release's system version. |

These packages use the current A/B software generation, not the legacy `.deb` update mechanism. RV1126B factory images and system bundles are for **TC358743 only**; they are not for other capture variants. App and system package checks still determine whether an installation is compatible.

Verify downloads against `SHA256SUMS`, which covers all nine packages and `BUILD-INFO.json`.

### Known issues and validation scope

No separate confirmed known-issue list is provided for this release. This is not a claim that the release is issue-free.

- CM4, H616 and RV1126B + TC358743 completed A/B system upgrades, activated the bundled App, committed their new slots and retained USB configuration. The running server and served UI matched their signed standalone App payloads.
- Device testing used **A/B upgrades**, not fresh factory-image flashing. Pi-family device testing covered **CM4**; Pi 4B had build/code coverage.
- USB configuration/readiness and short H.264 receive/decode samples were checked. Physical keyboard/mouse input and audio playback were **not claimed as tested**. The sample rates below are observations, not performance guarantees.

## 简体中文

### 主要变化

- **键鼠状态：**键盘与鼠标分别报告就绪状态；双鼠标模式分别显示绝对与相对路径，并提示部分就绪。已关闭的功能不降低总体连接状态；状态连接断开后会清除过期就绪状态。
- **更新检查：**使用固定的硬件与采集型号标识查找匹配版本；App 与系统分别检查并提供下载链接，检查更新不会自动安装。
- **安装包一致性：**三个平台均使用固定的前后端主线源码提交；完整镜像和系统包内置的签名 App 与对应的独立 App 包一致，并记录独立构建使用的源码与版本锁定信息。

### 升级说明

| 当前情况 | 选择与操作 |
| --- | --- |
| 首次安装或重装 | 下载对应 `.img.xz`，解压为 `.img` 后烧录；烧录会覆盖目标介质数据。 |
| 已有兼容 A/B 系统 | 在“系统升级”中安装对应 `.raucb`；重启后会启用内置的 App 3.0.1。 |
| 仅更新 App | 在“应用升级”中安装对应 `-app-3.0.1.tar.gz`，不替换操作系统。签名中的最低系统要求仍为 0.1.1，这是兼容下限，不是本次发布的系统版本。 |

这些安装包属于当前 A/B 软件体系，不使用旧版 `.deb` 更新机制。RV1126B 完整镜像和系统包**仅适用于 TC358743**，不能用于其他采集芯片版本；实际安装兼容性仍由 App 与系统包的检查决定。

下载后使用 `SHA256SUMS` 校验，范围包括九个安装包及 `BUILD-INFO.json`。
