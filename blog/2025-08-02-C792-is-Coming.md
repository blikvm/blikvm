The C792 HDMI-to-CSI-2 converter module is now available! This specialized converter designed for Raspberry Pi and Jetson platforms can transform 4K@60Hz HDMI input signals into 1080p@60Hz CSI-2 output, providing the perfect solution for your embedded video projects
with I2S audio capture.

![c792](/img/product/C792/C792-4.png)

## 🎯 Key Features

- **4K Input Support**: Up to 4K@60Hz HDMI input capability
- **Dual Output**: Simultaneous HDMI loop-out and CSI-2 conversion output
- **Audio Support**: I2S digital audio capture
- **Wide Compatibility**: Perfect support for Raspberry Pi series and Jetson platforms
- **Plug & Play**: No complex configuration required, quick setup

## 🔌 Interface Configuration

C792 provides two CSI-2 interfaces for different hardware:

- **15-pin FPC**: 2-lane, suitable for Raspberry Pi Zero/3B/4B
- **22-pin FPC**: 4-lane, suitable for Raspberry Pi CM4/5B and Jetson series

Besides, the I2S interface is also provided for audio capture.
