# 视频分析与延迟测量

入口：**设置 → 视频与摄像头 → HDMI 视频 → 分析**。界面可展示输入 / 输出状态、码率、帧率和支持的延迟统计。

## 查看数据

1. 固定电脑输出、网络和浏览器，先记录正常播放时的指标。
2. 需要分析时启用延迟统计，观察最近样本与 GRAB、ENC、LAT 等采集 / 编码时间戳。
3. 每次只改一个条件，例如画质档位或网络路径，再比较相同指标。
4. 完成后关闭不再需要的分析功能。

统计值的含义依赖测量起止点。编码耗时、网络往返和真实“电脑动作到屏幕显示”延迟不同，不能将其中一个当作全部端到端延迟，也不能从 demo 数值推导实机性能。

## 时间同步

页面可按需临时开启 BliKVM 局域网 NTP 服务，供测量环境校时；优先使用以太网。它与设备日常从网络校时、RTC 保持时间是不同任务，见[设备时间](../function/rtc.md)。

测试结束后关闭临时服务。开启 NTP 不会自动让所有客户端改用该设备，仍需在测试电脑中正确配置与验证时间同步。
