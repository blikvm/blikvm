# HDMI 环出

HDMI 环出把输入信号继续送到本地显示器；网络画面来自采集与编码，二者不是同一输出。

## 使用方法

1. 按型号接口图，将电脑接 HDMI 输入，本地显示器接 HDMI 输出。
2. 验证电脑、本地屏幕和网页画面能使用共同支持的输入模式。
3. 实机若提供**设置 → 视频与摄像头 → HDMI 视频 → HDMI 直通**开关，可按需控制并分别检查本地与网页画面。

物理具备环出接口，不代表当前系统一定提供软件开关。当前 H616 和树莓派采集适配不公布该软件控制能力；不要因菜单缺失而自行操作 GPIO。

本地显示器正常但网页黑屏，优先检查采集和视频传输；网页正常而本地屏幕不亮，则检查环出线路、显示器输入源和模式兼容性。最高 HDMI 输入能力不能直接当作网络编码分辨率，见[视频模式](./video-modes.md)。
