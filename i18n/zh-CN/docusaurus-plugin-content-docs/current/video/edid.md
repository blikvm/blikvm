# HDMI EDID

EDID 告诉被控电脑“这台显示设备支持什么输入模式”，不等于视频码率或浏览器显示缩放。入口：**设置 → 视频与摄像头 → HDMI 视频 → 显示器 EDID**，仅有写入能力的设备提供。

## 更换 EDID

1. 记录或保存当前 EDID，确认当前电脑仍有可用的显示管理途径。
2. 选择预设，或使用合法的自定义十六进制内容 / 文件，按界面应用。
3. 等待电脑重新识别显示设备，必要时在电脑侧重新检测或重新连接 HDMI。
4. 查看 HDMI 视频的输入格式，确认电脑实际输出了采集硬件支持的分辨率和刷新率。

自定义数据必须包含正确的长度、头信息和校验；复制一段分辨率文字不能生成 EDID。预设中出现某种分辨率，不代表当前采集硬件就能接受它。

## 不支持或黑屏

当前 v4 / H616 采集适配不提供软件 EDID 写入，不能套用 CSI 采集板的配置；树莓派与其他设备也应以实际公布的能力为准。没有入口时，不要修改旧路径中的 `edid.txt`。

若修改后无信号，先恢复已知可用 EDID，并将电脑输出降低到硬件支持的模式。EDID 更改不能修复 HDMI 线缆、供电或缺失的采集驱动。实际网页视频传输另见[视频模式](./video-modes.md)。
