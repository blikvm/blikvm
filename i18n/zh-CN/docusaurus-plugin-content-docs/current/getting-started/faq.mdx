# 常见问题与排查顺序

先记录设备型号、应用 / 系统版本和错误信息。一次只改一个条件，先局域网，再远程；不要把恢复出厂或刷机当作第一步。

| 现象 | 优先检查 | 详细指南 |
| --- | --- | --- |
| 无地址、网页打不开 | 电源、网线、DHCP、子网、端口和访问规则 | [网络](../network/notes.md) |
| HTTPS / 2FA / VPN 异常 | 地址、证书、设备时间及认证状态 | [证书](../network/https.md)、[账号](./auth.mdx) |
| 网页可用但黑屏 | 电脑电源、HDMI 方向、输入格式，再检查媒体连接 | [视频](../video/video-modes.md) |
| 局域网有画面，远程无画面 | ICE、VPN 路由、代理信令与媒体通路 | [WebRTC](../video/webrtc.md) |
| 有画面但键鼠无效 | USB 数据线、设备端接口、USB 类别和输入权限 | [USB](../peripheral-devices/usb.md) |
| 指针偏移或滚轮相反 | 绝对 / 相对模式、灵敏度和方向 | [鼠标](../peripheral-devices/keyboard-mouse/mouse.md) |
| 镜像已上传但不能启动 | 挂载状态、USB、架构、启动模式与启动顺序 | [虚拟介质](../peripheral-devices/msd.md) |
| 看不到功能入口 | 角色、细分权限、设备能力及镜像组件 | [界面指南](./web-interface.md) |
| 升级后断线或版本未变 | 同一次升级任务的状态、槽位与健康检查 | [更新](../function/update.md) |
| ATX / WOL 请求成功但未开机 | 接线或网络、固件与待机电源；请求成功不等于硬件已动作 | [ATX](../function/atx.md)、[WOL](../function/wake-on-lan.md) |

## 供电与 USB

使用型号要求的电源和数据线，区分供电口、USB 主机端与设备端。充电线可能没有数据通道，USB 反向供电也可能使电脑关机后部分电路仍上电。按对应型号指南使用需要的电源 / 数据分离附件，不要通过随意并联电源排错。

## 何时重启、重置或重装

服务重启用于已保存配置的应用；设备重启会中断当前连接；[恢复出厂](../function/factory-reset.md)删除受管理用户数据；[重装系统](./flashing-os.mdx)会重写存储介质。明确目标、保存信息并检查恢复途径，再选择相应操作。

## 反馈问题

按[诊断模板](../function/diagnostics.md)提供版本、访问路径、复现步骤和已去除凭据的日志。没有真实测试的数据，应明确标为模拟或待验证，不要从 demo 的成功画面推断硬件状态。
