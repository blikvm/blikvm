# 烧录 SD 卡与重装系统

重装适合系统无法恢复、首次安装或明确需要更换完整镜像的情况。日常版本更新优先使用[应用 / 系统升级](../function/update.md)，配置清理见[恢复出厂](../function/factory-reset.md)。

## 选择镜像

1. 核对硬件型号、SoC、存储介质及发布说明中的支持范围。
2. 从本站[下载固件](/zh-CN/download)入口选择对应型号的完整磁盘镜像，核对文件大小与提供的校验信息。
3. 备份需要保留的数据，并安排本地恢复。完整镜像、应用压缩包和 RAUC 升级包不能互相替代。

`.img` 是本流程使用的整盘镜像。压缩包应先核对内容和发布说明：其中若是 `.img`，解压后再写入；若是应用更新文件，应走应用升级流程。`.raucb` 是系统升级包，不能直接烧录到 SD 卡。不能把其他型号镜像改名后烧录。

## 按存储类型准备

| 介质 | 基本流程 |
| --- | --- |
| 可拆卸 microSD | 断电后取卡，通过读卡器写入匹配的完整镜像 |
| CM4 等板载 eMMC | 按型号手册进入 USB 启动 / 烧录模式，使主机识别目标存储，再写入 |
| 其他板载存储 | 使用该板和该发布版本明确指定的恢复工具，不能通用套用 SD 卡流程 |

使用能进行整盘写入和校验的工具，准确选择目标盘。写盘会覆盖所选存储，先断开无关移动磁盘，不能凭盘符顺序猜测。

## 烧录 microSD 卡：一步一步操作

本节适用于从可拆卸 microSD 卡启动的设备。使用板载 eMMC 的设备应先按型号说明进入烧录模式，不能把插入任意 SD 卡当作 eMMC 重装。

### 1. 准备镜像、SD 卡与工具

- 一台 Windows、macOS 或 Linux 电脑，以及可用的读卡器。
- 一张容量符合镜像发布要求的 microSD 卡；容量还需容纳解压后的完整镜像，不能只看压缩包大小。
- 从[下载固件](/zh-CN/download)选择与设备型号匹配的镜像。若提供校验值，下载完成后先核对。
- 从 [balenaEtcher 官网](https://etcher.balena.io/)下载安装适合电脑系统的版本。下面以 Etcher 为例，按钮名称可能随版本或语言略有变化。

:::warning 写入前备份
烧录会覆盖整张目标卡，包括原有系统、配置与文件。先备份，并断开无关的移动硬盘，核对目标卡容量与名称后再写入。
:::

### 2. 取出并连接 SD 卡

如果设备仍可正常操作，先正常关机，再断开电源。取出 microSD 卡，通过读卡器接到电脑。如果电脑询问是否格式化已有分区，先取消；本流程不需要预先手工格式化。

### 3. 选择镜像

打开 Etcher，点击 **Flash from file（从文件烧录）**，选择已下载并解压得到的 `.img` 文件。不要选择应用更新包或 RAUC 包，也不要把镜像文件直接复制到 SD 卡目录。

### 4. 选择目标卡

点击 **Select target（选择目标）**，按容量、名称和读卡器信息识别 SD 卡。若无法确认，可以先拔掉读卡器观察哪个设备消失，再插回并重新选择。

确认目标是要重装的 SD 卡，而不是电脑系统盘或备份盘。

### 5. 写入并等待校验

点击 **Flash!（烧录）**，按操作系统要求授予写盘权限。保持读卡器连接，等待写入和校验完成，看到成功提示后再继续。不能在进度条尚未结束时拔卡。

Etcher 提供写入校验，具体操作及失败排查见其[官方说明](https://etcher.balena.io/)。若失败，检查下载文件、读卡器、USB 接口和 SD 卡，修复后重新完成写入与校验。

### 6. 安全弹出并装回

若工具没有自动弹出目标卡，通过操作系统安全弹出后再拔下读卡器。将卡装回已断电的 BliKVM，连接网络和稳定电源，再按下一节检查首次启动。

烧录后的卡包含 Linux 分区，电脑可能提示有分区无法读取或需要格式化；不要为消除提示而格式化它。烧录成功只说明写入完成，还需要在设备上确认能够正常启动。

## 首次启动检查

1. 安全卸载介质，按型号要求装回并恢复启动模式。
2. 连接稳定供电与网络，等待初始化完成，不要中途断电。
3. 在路由器查找地址，按[首次使用](./first-steps.mdx)验证登录、HDMI 和 USB。
4. 核对系统 / 应用版本，再恢复所需配置；不要把旧版整套配置直接覆盖到新系统。

特定板卡烧录工具的按键、跳线和驱动应以该型号当前发布说明为准。不要把某一型号的跳线、驱动或恢复工具套用到其他型号。
