# 虚拟介质

虚拟介质将保存在 BliKVM 上的镜像，作为 USB 闪存盘或 CD/DVD 提供给被控电脑，可用于启动安装程序或救援系统。它不是浏览器与被控电脑之间的共享文件夹。

点击控制台工具栏中的**虚拟介质**进入。BliKVM 与电脑之间的 USB 数据连接及相应 USB 存储功能必须可用。账号需要虚拟介质使用权限，上传镜像还需要上传权限。

## 挂载安装镜像

1. 获取与被控电脑架构及启动模式匹配的安装镜像，并确认 BliKVM 存储空间足够。
2. 打开**虚拟介质**，选择 CD/DVD 镜像区域并上传 ISO。若实机提供从链接导入功能，它会将镜像下载到 BliKVM，设备本身需要能够访问该网址。
3. 等待传输完成，确认镜像出现在列表中。上传成功不代表已经挂载。
4. 点击该镜像的**挂载**，确认界面显示挂载状态并提供**弹出**操作。
5. 在被控电脑中进入固件启动菜单，选择相应 USB / CD/DVD 设备。启动按键和条目名称由电脑决定。
6. 确认安装或救援环境真正启动。使用结束后弹出镜像，避免电脑再次进入安装程序。

ISO 以只读 CD/DVD 方式提供。普通文件传输使用下方的闪存盘流程。把普通文件改名为 `.iso`，不会使它变成可启动镜像。

## 使用闪存盘传输文件

1. 切换到**闪存盘**标签。若尚未初始化，由管理员执行初始化；普通操作员的介质使用权限不包含初始化或销毁服务。
2. 保持闪存盘处于断开状态，在文件区域上传要传给电脑的普通文件。
3. 等待上传完成，点击**连接到主机**。被控电脑应出现一个 USB 磁盘，可以读取或写入文件。
4. 需要从被控电脑取回文件时，先在电脑上完成写入并安全弹出，再在网页中断开，刷新文件列表后下载所需文件。

连接到电脑时，网页上传区域会隐藏，避免两端同时修改文件系统。CD/DVD 镜像与闪存盘共用存储连接，切换到闪存盘可能会断开当前 CD/DVD 镜像，请按界面提示确认。

**销毁服务会删除虚拟磁盘及其数据**，不能把它当作日常“断开”按钮。从链接导入和初始化、销毁等管理操作需要设备配置权限，通常由管理员执行。

## 安全断开

对于可写闪存介质，先在被控电脑的操作系统中完成写入并安全弹出，再从 BliKVM 断开。安装系统或磁盘写入期间，不要删除、替换或断开正在使用的镜像。断开后确认电脑已不再使用，再删除设备中保存的文件。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 上传或导入失败 | 剩余空间、上传权限、网络连接，以及 BliKVM 能否访问镜像网址。 |
| 上传完成但电脑看不到磁盘 | 是否已经挂载、USB 数据连接和存储功能是否开启。 |
| 能识别介质但无法启动 | 镜像架构、UEFI / 传统启动模式、安全启动要求及电脑启动顺序。 |
| 系统装好后又进入安装程序 | 弹出镜像或调整电脑启动顺序。 |
| 修改 USB 后键鼠异常 | 检查 USB 功能组合及电脑兼容性；重新配置 USB 可能触发设备重连。 |

USB 设备功能应通过当前网页设置调整。旧文档中的 `/mnt/exec/release/config/app.json` 存储配置，不适用于当前软件的配置流程。
