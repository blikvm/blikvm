# USB 功能与虚拟网络

入口：**设置 → 键鼠与 USB**。BliKVM 的 USB 设备端向被控电脑模拟键盘、鼠标、存储、音频、摄像头或网卡；主机端则用于插入真实 USB 外设，方向不同。

## 配置功能组合

1. 记录当前组合，确认仍有网页管理入口。
2. 选择默认、仅键盘或自定义。需要自定义时进入**自定义USB功能**。
3. 仅开启任务所需的类别，并查看 **USB 端点容量**。
4. 应用 USB 功能后等待重新枚举，在电脑设备管理器和控制台中验证。

每个平台的 IN / OUT 端点预算不同；超过预算的组合不能选择。不能照搬另一型号的类别组合，也不应为了打开摄像头而无意关掉键鼠。更改可能短暂中断键鼠、虚拟磁盘或音频。

## USB 标识符

标识符页面配置电脑识别到的 VID、PID、制造商、产品名和序列号。它不会改变真实芯片或增加驱动能力。兼容性排查优先从默认值和最少功能组合开始，避免随意使用其他产品的标识符。

## USB 虚拟网络

在自定义功能中启用 USB 网络，并进入配置。设置设备地址、DHCP 及所需网络共享；关闭 DHCP 时，电脑必须手动配置同网段地址，涉及共享时还需正确网关和 DNS。

网络共享使被控电脑可以访问 BliKVM 的上行网络，应在了解网络边界后启用。上行跟随首选网络；保存后按提示更新电脑的 DHCP 租约，并分别验证本地维护访问和外连。
