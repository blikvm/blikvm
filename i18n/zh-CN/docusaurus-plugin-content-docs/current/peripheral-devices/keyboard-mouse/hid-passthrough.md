# 本地键鼠 USB 直通

入口：**设置 → 键鼠与 USB → USB 直通**。将接在 BliKVM USB 主机端的实体键盘、鼠标输入，转发给被控电脑。

这与浏览器键鼠输入、USB 网络和任意 USB 设备重定向是不同功能；不要据此假设可透传打印机、加密狗或其他 USB 类设备。

## 启用并验证

1. 将实体键鼠接入 BliKVM 的 USB 主机端，同时保留 BliKVM 到电脑的 USB 设备端数据线。
2. 打开直通页面，检查是否检测到本地键盘、鼠标。
3. 如需鼠标直通，在 USB 自定义功能中启用相对鼠标，并选择包含相对输入的模式。
4. 启用直通，确认状态为运行或已抓取，再测试实体输入。
5. 按需设置滚轮反向，使用结束后关闭直通。

“已启用，等待设备”表示尚未找到可用输入源，不代表已转发成功。当前系统可能抓取这些本地输入设备供转发使用。配置需要相应设备管理权限，操作权限由当前账号控制；无需编辑旧 `pass_through` 配置文件。
