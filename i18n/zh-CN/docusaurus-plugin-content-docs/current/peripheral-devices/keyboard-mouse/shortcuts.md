# 屏幕键盘与键盘宏

控制台工具栏提供**键盘**和**键盘宏**。网页或本机操作系统可能先拦截组合键，屏幕键盘适合发送这类按键。

## 发送组合键

1. 将被控电脑切换到目标程序或界面。
2. 打开屏幕键盘，选择所需修饰键和按键。
3. 观察电脑的响应，确认修饰键已释放，再继续其他输入。

不要在不确认窗口焦点时发送关机、删除或固件配置按键。

## 建立键盘宏

1. 打开键盘宏，新增并命名。
2. 按界面组合按键、文本和等待步骤；为需要加载的程序保留等待时间。
3. 保存后先用无破坏性的短序列测试。
4. 需要复用时使用导入 / 导出，导入前核对内容。

键盘宏只按序发送输入，不理解电脑当前状态，也不会验证安装是否成功。录入密码的宏及导出文件会包含敏感文本，应避免共享。执行宏需要输入自动化权限；普通输入需要键鼠控制权限。

大量文本输入、非 ASCII 文字和网页 OCR 的限制，见[粘贴与文本提取](../paste-ocr.md)。当前宏管理不需要编辑旧快捷键 JSON 配置。
