# 鼠标模式与触控

入口：**设置 → 键鼠与 USB**。鼠标能否工作同时取决于 USB 类别、当前鼠标模式与网页输入偏好，不是视频编码问题。

## 选择合适的输入方式

- **绝对坐标**：直接定位到画面位置，适合支持绝对指针的桌面系统。
- **相对移动**：发送位移，适合部分 BIOS、旧系统或捕获指针的程序；灵敏度受电脑的鼠标加速影响。
- **双模式**：设备同时提供两类鼠标时，可在网页切换行为，无需每次重建 USB 设备。

在键鼠页检查当前设备模式。双模式下切换绝对 / 相对行为，必要时调整相对灵敏度、滚轮灵敏度或滚轮方向；USB 类别变更见 [USB 功能](../usb.md)。

## 验证与修复

1. 先确认 USB 数据线与账号输入权限正常。
2. 在桌面和 BIOS 中分别测试移动、点击、拖动及滚轮。
3. 指针不同步时，比较绝对 / 相对模式，而不是同时修改多项加速和视频参数。
4. 恢复默认后仍异常，记录电脑系统、模式和 USB 功能组合。

手机或平板的触控输入，在**设置 → 界面偏好 → 输入方式**选择自动、鼠标或触控。该偏好只保存在当前浏览器，不会改变被控电脑的 USB 硬件模式，详见[界面偏好](../../function/interface-preferences.md)。
