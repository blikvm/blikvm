# 鼠标抖动器

入口：**设置 → 键鼠与 USB → 鼠标抖动器**。账号需要输入自动化权限。

启用后，设备定期发送轻微鼠标移动，以减少被控电脑因为完全无输入而进入空闲状态。当前网页使用开关控制固定间隔，不再要求编辑 `jigglerTimeDiff` 或重启旧服务。

## 使用步骤

1. 先验证鼠标控制和 USB 数据连接正常。
2. 打开抖动器开关，观察界面是否成功更新。
3. 在无其他输入的情况下观察电脑是否收到轻微移动。
4. 完成任务后关闭，确认不再自动移动。

它不会替你修改系统电源策略，也不能保证避开所有锁屏、休眠或安全策略。多个用户共享电脑时，应先协调，避免自动移动干扰手动操作。若没有权限或当前 USB 鼠标功能未启用，应先解决前置条件。
