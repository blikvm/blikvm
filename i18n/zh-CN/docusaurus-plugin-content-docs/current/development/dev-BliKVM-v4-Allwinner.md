# v4 板级硬件参考
![主图](/assets/images/v4/Datasheet-BliKVM-v4.assets/Main.png)

BliKVM 是一款即插即用的生产级 KVM-over-IP 设备，为专业用户提供了**远程服务器或工作站管理**的便捷解决方案。它运行基于 Linux 的系统。通过 BliKVM，您可以轻松地**开机/关机、重启计算机、配置 UEFI/BIOS 设置，以及通过模拟的存储设备执行操作系统重装**。BliKVM 模拟键盘、鼠标和显示器，所有功能均可通过网络浏览器访问，确保流畅的用户体验。**其硬件级访问保证了对特定远程端口、协议或服务的独立性**，使其成为专业人士高度灵活且可靠的远程管理解决方案！

:::info 参考范围
下面保留 v4 的板级框图与接线信号。旧式全局 GPIO 编号不等同于当前 gpiochip 的 line offset，也不是网页用户应执行的控制命令。本页仅作硬件参考，日常操作见[v4 设备指南](../device-guides/BliKVM-v4-guide.mdx)。
:::

## 功能模块

### 面板

| 功能       | 引脚         | 描述                               |
| ---------- | ----------- | ----------------------------------- |
| 按钮 SW1   | GPIOI1(257) | 按下为高电平                       |
| 按钮 SW2   | GPIOI2(258) | 按下为高电平                       |
| LED ACT    | GPIOI5(261) | 低电平点亮 LED                     |
| LED PWR    | 3V3         | 上电后 PWR LED 始终点亮            |

### ATX

| 功能      | 引脚          | 描述                   |
| --------- | ------------ | --------------------- |
| LED-PWR   | GPIOH10(234) | 高电平点亮            |
| LED-HDD   | GPIOH9(233)  | 高电平点亮            |
| SW-PWR    | GPIOH4(228)  | 高电平使能            |
| SW-RST    | GPIOI16(272) | 高电平使能            |

### 蜂鸣器

| 功能      | 引脚          | 描述                 |
| --------- | ------------ | ------------------- |
| 蜂鸣器    | GPIOI15(271) | 高电平使能          |

### 风扇

| 功能      | 引脚          | 描述                 |
| --------- | ------------ | ------------------- |
| 风扇      | GPIOI13(269) | 高电平使能          |

### LCD 显示屏

1.33 英寸 LCD 显示模块，驱动芯片 ST7789，分辨率 240x240。

| 功能       | 引脚         | 描述                           |
| ---------- | ----------- | ----------------------------- |
| LCD_EN     | GPIOI4(260) | 背光高电平使能                |
| LCD_RST    | GPIOI6(262) | 复位低电平使能                |
| LCD_DC     | GPIOI3(259) | 数据/命令控制引脚             |
| SPI1_CS    | GPIOH5      |                               |
| SPI1_CLK   | GPIOH6      |                               |
| SPI1_MOSI  | GPIOH7      |                               |
| GND        | GND         |                               |
| 3V3        | 3V3         |                               |
