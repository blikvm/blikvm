# 网络连接与路由

BliKVM 的网络用于打开网页、协商媒体连接，以及访问 VPN、DDNS 和升级包等服务。先在局域网验证，再配置远程入口，避免同时更改地址、端口和路由。

## 查看当前连接

进入**设置 → 网络 → 接口与地址**，查看接口、MAC、IPv4、IPv6 和 DHCP 信息。多个网口、Wi-Fi、VPN 同时在线时，每个接口可能有不同地址。

- [静态 IP 与 DHCP](./static-ip.md)：配置接口地址、网关和 DNS。
- [Wi-Fi](./wifi.md)：连接无线网络，按设备能力使用热点。
- [HTTPS 与端口](./https.md)：管理网页入口和证书。
- [远程访问选择](./internet-access/overview.md)：比较 VPN、端口转发和隧道。

## 选择上行网络

进入**设置 → 网络 → 上行与路由**，查看已连接的以太网、Wi-Fi 和默认路由。选择首选上行后应用；选择自动可恢复系统原有路由优先级。该设置用于新的 IPv4 / IPv6 外连，不会替你重写 VPN 的专用路由。

修改前记录当前地址和可用入口。若两个接口处于重叠子网，应先规划不同网段；更换上行后，检查 DNS、外网访问和远程视频，而不只是能否打开局域网页。

## 分层排查

| 检查 | 成功说明 | 不代表什么 |
| --- | --- | --- |
| 打开设备网页 | 当前地址和网页端口可达 | WebRTC 已连通 |
| 能登录 | 账号、认证和访问规则允许 | 当前角色可以控制或维护 |
| 看到画面 | HDMI 及所选传输可用 | USB 输入正常 |
| 能操作电脑 | 输入权限和 USB 链路正常 | ATX、虚拟介质等可选功能均已验证 |

网页可用但远程无画面，查看 [WebRTC 排查](../video/webrtc.md)。不要再使用旧版 Janus 的接口屏蔽配置来解决当前版本的多网口问题。
