# 公网端口转发

需要可从外部入站的公网地址，以及路由器或转发服务器管理权限。运营商 CGNAT 下，单纯添加端口规则通常不能形成公网入口，可改用 VPN 或自有中继方案。

## 配置固定 WebRTC UDP 端口

1. 在局域网进入**设置 → 远程访问 → 端口转发**。
2. 启用固定 UDP 端口，选择可用端口（界面允许 `1024–65535`），按需填写公布的公网 IPv4。
3. 保存并应用；该操作可能重启服务并中断视频和终端。
4. 在路由器或公网服务器中建立 HTTPS TCP 与同一固定 UDP 端口的转发规则，并允许防火墙流量。网页只配置设备，不会替你创建路由器规则。

默认 HTTPS 入口的示意：

```text
公网 TCP 443 → BliKVM HTTPS 443
公网 UDP 所选端口 → BliKVM UDP 同一端口
```

若实际网页端口已修改，需要相应调整 HTTPS 规则和访问地址。保持 UDP 端口内外一致，避免公布的端点与实际映射不符。关闭固定模式后，恢复原有随机端口机制，手动公布地址不再按固定模式使用。

## 验证与回退

使用外部网络测试网页和视频；局域网仍可使用局域网地址。若提示固定传输不可用，先检查端口占用和服务状态，必要时关闭固定模式并应用。公网环境启用强认证和可信 HTTPS；STUN/TURN 配置位于[视频高级设置](../../video/webrtc.md)，不会由这个页面自动替换。
