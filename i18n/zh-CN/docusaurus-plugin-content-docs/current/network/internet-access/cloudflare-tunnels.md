# HTTP 隧道与 Cloudflare Tunnel

HTTP 隧道可将设备网页发布到域名入口，但它不等于完整的 WebRTC 媒体隧道。当前网页没有通用的 Cloudflare Tunnel 一键安装配置页，需要在自己的隧道主机上部署和管理。

## 接入步骤

1. 先在隧道主机上确认设备 HTTPS 地址可达。
2. 按所选隧道服务的管理流程建立域名到设备的 HTTPS 转发，并处理上游证书信任。
3. 保持设备认证开启，确认 WebSocket、Cookie、长连接和上传限制与需求匹配。
4. 在外部网络测试网页登录，再单独验证视频、终端及输入。

若网页正常而视频不通，不应反复关闭认证或改用不安全协议。可使用已配置的可达 TURN / VPN 媒体通路，或选择实机提供且适合该部署的模式。有关限制见[反向代理](./reverse-proxy.md)和 [WebRTC](../../video/webrtc.md)。

服务商的访问策略、带宽与使用条款由部署方确认；本文不把第三方隧道视为无限制的视频中继，也不提供需要复制凭据的公共安装命令。
