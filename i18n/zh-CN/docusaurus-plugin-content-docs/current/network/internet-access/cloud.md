# BliKVM 云平台

入口：**设置 → 远程访问 → BliKVM 云平台**，仅支持该能力的设备和系统会提供。当前 v4 与树莓派适配不开放云绑定入口；其他设备也应以实机能力为准。

## 绑定

1. 确认设备认证已开启，并有管理员权限。
2. 在你使用的云平台控制台创建配对码。
3. 在设备中填写正确的云平台地址和配对码，执行绑定。
4. 等待界面从未绑定 / 离线变为已连接，再从云端打开设备。
5. 用外部网络验证视频和输入。页面提供的设备网络诊断可检查配置的 STUN/TURN 可用性，但不能代替浏览器到设备的完整连通测试。

## 媒体与解绑

云平台提供访问管理入口，**不提供视频中继**；视频通过 WebRTC 直连或你配置的 TURN 传输。无法直连时，检查 TURN 或使用 VPN。

设备转交他人或停用时，应完成解绑并核对云端设备列表。恢复出厂设置会清除本地绑定；若云端解绑未能确认，还需要在云账号中手动移除相应条目。配对码和云凭据不要出现在公开截图中。
