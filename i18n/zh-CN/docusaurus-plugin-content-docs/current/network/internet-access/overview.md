# 选择远程访问方式

先按[首次使用](../../getting-started/first-steps.mdx)验证局域网。远程访问至少包含网页入口、认证和媒体网络三部分，不能只验证首页能打开。

| 方式 | 适用条件 | 必须另外验证 |
| --- | --- | --- |
| WireGuard | 已有可管理的 VPN 服务与配置文件 | 隧道路由、地址不冲突、设备和客户端均在线 |
| Tailscale / ZeroTier | 可以访问对应控制服务并授权设备 | 账号 / 网络授权、访问策略、直连或中继路径 |
| 端口转发 | 有可入站的公网地址及路由器管理权 | HTTPS 与 WebRTC UDP、认证和防火墙 |
| 反向代理 / HTTP 隧道 | 有现成代理或隧道部署 | WebSocket、超时及独立的媒体通路 |
| BliKVM 云平台 | 设备能力与所部署云服务支持绑定 | 云端授权、直连或自配 TURN；云平台不提供视频中继 |

## 验证顺序

1. 从真正的外部网络访问，例如管理电脑使用手机热点，避免局域网回流造成误判。
2. 测试登录、持续视频和一次无破坏性的键鼠操作。
3. 验证会话重连及需要使用的虚拟介质 / 终端功能。
4. 比较局域网与远程结果；记录浏览器、模式、设备版本和错误文本。

多个方案可以组合，但应一次添加一种。DDNS 只更新域名解析，不提供 VPN、端口转发或中继。安全规则见 [IP 访问控制](../security.md)。
