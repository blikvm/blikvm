# WireGuard

入口：**设置 → 远程访问 → WireGuard**。先准备与现有 VPN 服务匹配的 `wg0.conf`；本页管理设备端隧道，不会自动部署 VPN 服务器。

## 上传并启用

1. 由 VPN 管理员分配独立隧道地址和密钥，配置对端、Endpoint、AllowedIPs 及所需 DNS。
2. 在页面选择配置文件，使用**上传**，或**上传并启用**。
3. 核对已保存配置、服务状态与隧道 IP。需要备份时使用**下载当前文件**，妥善保管其中私钥。
4. 让管理电脑加入同一可路由网络，通过页面给出的 VPN 访问地址打开 BliKVM。
5. 验证视频和输入，再测试刷新后的重连。

## 常见问题

- 无握手：核对服务端 Endpoint、UDP 可达性、密钥与对端配置。
- 有握手无访问：核对 AllowedIPs、双方路由、防火墙和地址冲突。
- 配置存在但服务未启用：上传文件和启动隧道是独立状态。
- 启用后其他外连异常：检查默认路由是否被配置接管，以及 DNS 是否可达。

使用网页入口无需执行旧版的包安装、`iptables` 或 `systemctl` 示例。`0.0.0.0/0` 等全流量路由会改变设备外连，应由了解网络拓扑的管理员决定，而不是作为通用必填值。
