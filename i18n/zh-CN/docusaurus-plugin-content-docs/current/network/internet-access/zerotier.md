# ZeroTier

入口：**设置 → 远程访问 → ZeroTier**。镜像需包含相应服务，管理电脑应加入同一个获授权的虚拟网络。

## 配置流程

1. 在自己的控制端创建或选择网络，获取 Network ID。
2. 在 BliKVM 填写网络 ID，保存并启用。
3. 查看设备的 Node ID、加入状态和网络名称，在控制端对这个节点授权。
4. 等待状态就绪且取得地址，再从授权客户端打开设备。
5. 验证登录、视频和输入，不要只根据“服务运行中”判断全部成功。

## 排查

节点一直等待授权时，到控制端核对 Node ID；已加入但没有地址时，检查控制端的地址分配。能够访问网页但媒体连接失败时，检查虚拟网络策略及 [WebRTC](../../video/webrtc.md)。

不要把服务启用与控制端授权混为一步，也无需按旧指南重新安装 ZeroTier。切换网络前记录原网络与可用局域网入口。
