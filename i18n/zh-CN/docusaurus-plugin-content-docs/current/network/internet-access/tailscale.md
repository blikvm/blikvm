# Tailscale

入口：**设置 → 远程访问 → Tailscale**。设备镜像需包含相应服务，管理电脑也需加入同一可访问网络。

## 加入网络

1. 从自己的 Tailscale 管理环境准备有效 Auth key。
2. 在设备页面填写 Auth key，按需设置控制服务 URL、主机名、通告路由及接收子网路由。
3. 保存配置，再启用服务。已保存的 key 会按界面提示复用，替换时再输入新值。
4. 等待设备取得 VPN 地址，并在控制端完成所需审批和访问策略。
5. 从另一台授权客户端，通过页面提供的地址访问，验证登录和视频。

只需访问 BliKVM 时，不必通告整个局域网路由。控制服务 URL 留空时使用服务自身默认配置；自建控制服务需保证兼容及可达。

## 连接未完成

“已启用，等待连接”不同于已加入网络。检查密钥有效性、设备时间、DNS、上行网络和控制端审批。显示 VPN 地址后仍无法访问，应检查访问策略和路由。网页正常但无视频时，再看 [WebRTC 排查](../../video/webrtc.md)。

本指南使用设备内置管理入口，不要求在设备上运行外部安装脚本。Auth key 属于凭据，不要放在截图或共享日志中。
