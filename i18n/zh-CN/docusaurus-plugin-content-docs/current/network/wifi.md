# Wi-Fi 连接

需要支持无线网卡及当前系统驱动。以实机菜单为准；没有无线硬件时，网页不会让它凭空获得 Wi-Fi 能力。

## 连接无线网络

1. 先通过网线登录，进入**设置 → 网络**中的 Wi-Fi 页面。
2. 扫描网络，选择 SSID，按页面填写密码并连接；隐藏网络需按界面提供的手动连接方式填写。
3. 等待连接状态和地址更新，在**接口与地址**中确认无线接口取得地址。
4. 从同一无线网络中的另一台设备测试新地址。确认可用后再决定是否移除网线。

无线接入点的客户端隔离、访客网络和 VLAN 可能阻止管理电脑访问 BliKVM，即使 Wi-Fi 状态显示已连接。若掉线，先检查信号、频段、供电及网络侧规则，不要修改配置目录的全局文件权限。

## v4：通过前面板双键配网

包含新版 v4 小屏配网服务及适配驱动的镜像，可在没有网线时**同时长按 BUTTON 1 + BUTTON 2 约 3 秒**，通过小屏显示的临时热点完成无线连接。进入热点后打开 `http://192.168.4.1`，选择目标网络；连接时热点关闭，随后按小屏显示的新 IP 访问设备。

完整的操作、示意图、失败重试与退出方式见[v4 Wi-Fi 配网](/zh-CN/docs/device-guides/BliKVM-v4-guide#wifi-setup)。热点密码每次生成，以实机小屏为准；扫码失败时可手动输入 SSID 和密码。旧镜像可能没有此功能，不能仅凭网页应用版本推断支持。

## 热点与上行

前面板触发的**临时配网热点**与网页网络设置中的**长期热点 / AP 功能**不同。网页是否提供长期热点入口由平台能力决定；不能据此判断 v4 是否支持上述本地配网。树莓派等其他平台也不能直接套用 v4 双键流程。

同时连接有线和无线时，在[上行与路由](./notes.md)选择首选外连接口。Wi-Fi 已连接并不等于具有互联网出口；VPN、DDNS 还需要正确的路由、DNS 和时间。
