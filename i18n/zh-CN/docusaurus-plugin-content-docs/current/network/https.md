# HTTPS、证书与网页端口

当前界面的网页入口使用 HTTPS，HTTP 端口用于重定向。进入**设置 → 网络 → 网页服务端口**，以设备实际返回的配置为准。

## 修改端口

1. 记录当前 HTTPS 地址，并确认新端口未被其他服务占用。
2. 填写 HTTP 重定向端口与 HTTPS 端口，点击**保存并应用**。
3. 服务会重启，网页、视频和终端可能短暂断开。使用界面提示的新地址重连，非默认端口需保留 `:端口`。
4. 检查反向代理、路由器映射、书签和防火墙是否也需调整。

## 首次访问与可信证书

设备自签名证书可能触发浏览器警告。先核对设备地址及证书，再由设备管理员处理信任；不要忽略陌生站点的警告。摄像头、麦克风和剪贴板等浏览器功能通常要求安全上下文，能打开网页不等于相关权限已经可用。

需要受信任的域名入口时，可由[反向代理](./internet-access/reverse-proxy.md)提供证书。设备自身证书的运维位置见[持久化目录与日志](../development/architecture.md)，网页目前没有通用的证书上传向导。证书更新、私钥权限和服务重启应按所装镜像的部署机制处理，不能套用旧的 `app.json` 配置。

恢复出厂设置会重新生成设备 TLS 和 SSH 身份，地址也可能改变，届时需重新核验指纹。浏览器本地信任和偏好不会因为设备重置而自动清除。
