# 静态 IP 与 DHCP

入口：**设置 → 网络 → 接口与地址**。需要设备配置权限。优先使用路由器的 DHCP 地址保留，可让地址固定，同时保留集中管理。

## 配置静态 IPv4

1. 记录当前接口、地址及 MAC，确认准备修改的是正在使用的物理接口。
2. 将 IPv4 模式切换为静态，填写地址、子网掩码、网关和 DNS。地址必须属于正确网段，且没有被其他设备占用。
3. 点击保存，核对变更确认框中的新旧值，再应用。
4. 若连接断开，用新地址重新打开设备，验证登录、视频及设备外连。

例如局域网为 `192.168.1.0/24`，可由网络管理员分配一个未占用地址；不要直接复制示例或使用 DHCP 池中会被重复分配的地址。无网关的隔离网仍可局域网访问，但不能据此期待 VPN 或 DDNS 正常外连。

## 返回 DHCP

选择 DHCP 并保存应用，随后从设备显示屏或路由器租约列表查找新地址。IPv6 地址在接口页单独显示，不要把链路本地地址当成公网地址。

## 保存后无法访问

检查电脑与设备的子网、地址冲突、网关、VLAN 和 IP 访问规则。不要连续修改多个接口；没有备用入口时，应在能够接触设备的环境中变更。当前指南不需要运行 `raspi-config`、`armbian-config` 或修改旧版网络配置文件。
