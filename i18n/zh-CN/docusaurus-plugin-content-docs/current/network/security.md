# IP 访问控制与审计

账号认证决定“谁能操作”，IP 规则限制“从哪里进入”。入口：**设置 → 账号与安全 → IP 访问控制**，仅管理员可修改。

## 设置 IP 规则

1. 确认当前连接来源，并记录备用管理员入口；VPN、代理可能改变设备实际看到的来源地址。
2. 将 IPv4、IPv6 或 CIDR 网段加入允许列表或阻止列表。
3. 检查条目，再选择允许列表、阻止列表或不启用规则的模式。
4. 重新从实际管理网络验证，不要仅看保存成功。

允许列表模式至少需要有效条目。当前实现会拒绝直接阻断本次来源的修改，但这不等于所有未来代理路径都能访问。不要将任意转发头当作设备已验证的客户端地址。

## 审计和自动化凭据

管理员可在账号管理的审计区域查看记录；API 为 `GET /api/v1/audit`，需审计读取权限。事件应结合操作者、时间、动作和结果分析，不能把一条请求记录当作硬件动作已完成的证明。

账号管理中的个人 API 令牌可分配当前账号具备的权限子集，并设置有效期；令牌只在创建时完整显示，应及时保存与撤销。详见[账号与安全](../getting-started/auth.mdx)和 [API](../development/api.mdx)。

浏览器会话、API 令牌、VPN 密钥和操作系统 SSH 凭据各有独立生命周期。排查访问问题时，应分别检查认证、权限、IP 规则、网络和设备能力。
