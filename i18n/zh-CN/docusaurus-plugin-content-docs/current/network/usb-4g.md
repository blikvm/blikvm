# USB 4G 网卡

USB 4G 网卡可让 BliKVM 通过移动数据上网。已在 **BliKVM v4（H616）、Raspberry Pi 4B 和 RV1126B（TC358743）** 上实测 **华为 E8372h-820 的 HiLink USB 以太网模式**。以下步骤以该网卡为例。请使用带 USB 4G 状态卡的 BliKVM 应用，以及支持 USB 以太网驱动的系统。RV1126B 需要升级到包含 CDC Ethernet 驱动的系统版本。

## 接入并查看状态

1. 将已开通移动数据的 SIM 卡插入网卡，再把网卡接到 **BliKVM 的 USB 主机接口**。配置期间保留可用的有线或 Wi-Fi 管理连接。
2. 打开**设置 → 网络 → 网络详情**，查看 **USB 4G 网卡**。进入 USB 以太网模式后，网卡会通过 DHCP 分配 IPv4 地址和网关。卡片会显示接口、IPv4 地址、网关，以及设备端的收发字节数。
3. 如果网卡与有线或 Wi-Fi 使用了重叠的网段，请在 HiLink 管理页调整网卡的局域网网段。例如，实测网卡在 `192.168.9.0/24` 网段使用网关 `192.168.9.1`，管理网络使用其他网段。

若卡片提示 USB 串口模式，请拔下网卡，等待几秒后重新插入。若一直停在启动状态或提示无网络接口，请检查网卡是否进入 HiLink USB 以太网模式，并确认当前系统已包含 USB 以太网驱动。

## 将 4G 用作备用上行

在**设置 → 网络 → 上行与路由**中将有线或 Wi-Fi 设为首选。**IPv4 备用出口**表示首选 IPv4 默认路由仍经过其他接口。该路由撤销后，4G 网卡可以接管。**正在用作 IPv4 出口**表示默认路由已选中该网卡。验证远程访问时，可通过 4G 测试现有的 [VPN 连接](./internet-access/overview.md)，并在首选网络恢复后确认连接切回。通过 4G 传输的视频和下载会消耗 SIM 卡流量。
