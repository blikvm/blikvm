# 设备终端与 SSH

**设置 → 高级与诊断 → SSH 终端**打开的是 BliKVM 自身管理终端，不能当作被控电脑桌面或串口。当前网页终端通过已认证的实时通道连接设备服务。

## 网页终端

1. 使用拥有设备终端权限的账号登录。
2. 打开入口，先用 `date`、`uname -a` 等只读命令确认目标环境。
3. 进行与当前镜像匹配的管理操作，结束后关闭终端并退出账号。

管理员终端能够改变设备系统。未知脚本、错误分区命令和网络配置都可能中断远程管理；网页断开也不一定使已启动的后台任务停止。

## 独立 SSH 客户端

若镜像提供 SSH 服务，可从自己的终端按实际地址、端口及操作系统账号连接：

```sh
ssh 用户名@设备地址
```

网页账号与操作系统 SSH 账号分开管理，不能认为 `admin/admin` 或旧镜像的 `blikvm/blikvm` 必然适用。SSH 主机指纹变化时，先核对是否刚重装或恢复出厂，再更新客户端信任。

需要访问被控设备的串口时，使用[串口终端](./serial-terminal.md)；不需要在旧网页配置中保存操作系统 SSH 密码。
