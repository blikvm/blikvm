# 存储空间与数据

当前原生系统将应用、运行数据和私密凭据分开管理，用户可见的虚拟介质空间不等于根文件系统剩余空间。

## 查看和释放空间

1. 在**虚拟介质**查看实际用于镜像和闪存盘的存储占用。
2. 先完成被控电脑写入并弹出介质，再删除不再需要的镜像或文件。
3. 通过[诊断信息](./diagnostics.md)核对是否为日志、失败上传、镜像或其他数据占用。
4. 需要离线调整分区时，先备份，并按当前系统镜像的布局说明操作。

## 不要直接套用旧扩容命令

A/B 系统包含活动槽、备用槽和数据区域。旧指南中按固定 `/dev/mmcblk0p2` 执行分区扩容、`raspi-config` 或任意脚本，可能破坏启动和回退布局。卡容量变大，不代表所有分区都需要手动扩大。

重装镜像与恢复出厂设置都可能丢失数据；应用 / 系统更新也不能代替数据备份。应分别保存虚拟介质中的必要文件、VPN 配置和需要保留的自定义脚本，私钥与账号备份单独保护。

运行目录供开发运维参考，见[持久化目录与日志](../development/architecture.md)。普通使用不需要手工删除状态目录或把只读系统整体重新挂载为可写。
