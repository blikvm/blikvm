# 恢复出厂设置

入口：**设置 → 设备与系统 → 恢复出厂设置**。这是会删除数据的设备重置，不是普通重启、应用回退或系统重装。

## 会删除和保留什么

| 会清除 | 不会因此恢复或删除 |
| --- | --- |
| 设备账号、密码、2FA、会话与 API 令牌 | 已安装应用 / OS 版本及升级回退元数据 |
| 设置、网络 / VPN / 插件状态、云绑定 | 硬件身份及校准数据 |
| 自定义 EDID、脚本、终端历史、虚拟介质 | 浏览器本地偏好及系统镜像内置 SSH 密码 |
| TLS 证书和 SSH 主机密钥 | 未受管理的文件、手工凭据备份或外部数据 |

它不是安全擦除；软件回退也不会找回已删除的用户数据。

## 执行前与流程

1. 备份需要的文件和配置，确认能够接触设备进行恢复，并停止所有介质写入、完成弹出。
2. 管理员打开页面，核对删除范围，输入当前管理员密码；启用 2FA 时还需当前验证码。
3. 核对最终确认后再提交。设备将排队执行重置并经历两次重启，等待完成。
4. 地址可能恢复为 DHCP，从路由器重新查找；核对并重新信任新 TLS / SSH 指纹。
5. 重新配置账号、网络和需要的服务，确认基本功能。

当前实现仅对支持原生数据布局和默认初始化机制的镜像开放，预检查失败时不要强行删除目录。若中途失败，设备可能保留重置请求并阻止应用启动，应按错误修复后恢复流程，而不是删除请求来掩盖不完整状态。

如提示云端解绑未确认，还应到云控制台手动移除设备。本文仅说明流程，文档制作过程中没有执行恢复出厂操作。
