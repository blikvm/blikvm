# 系统脚本

入口：**设置 → 高级与诊断 → 系统脚本**。仅管理员管理，脚本在 BliKVM 自身执行，不是被控电脑命令，也不是浏览器键盘宏。

## 上传与运行

1. 准备与镜像兼容的 `.sh` 文件；执行解释器为 POSIX `/bin/sh`，不要默认 Bash 扩展可用。
2. 上传后查看内容，再手动运行，检查退出码和日志。
3. 先确认手动运行可靠，再决定是否随启动执行。

## 运行模式

| 模式 | 行为 |
| --- | --- |
| 仅手动 | 只在明确执行时运行 |
| 启动时运行一次 | 启动时执行一次任务，不等于持续服务 |
| 常驻服务 | 按配置管理长期进程，可选择始终、失败时或不重启，以及重启延迟 |

日志中的运行、退避重启、退出和失败是不同状态，保存配置不等于脚本已成功完成。错误的常驻任务可能持续消耗资源，应检查重启策略与设备负载。

脚本可能访问设备数据和网络。不要上传来源不明的脚本，也不要把凭据写进共享文件。恢复出厂会清除受管理脚本及配置，重要内容应单独备份。
