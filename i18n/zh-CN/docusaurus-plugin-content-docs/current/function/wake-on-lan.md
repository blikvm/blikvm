# 局域网唤醒（WOL）

入口：**设置 → 网络 → Wake on LAN**。WOL 向电脑网卡发送 Magic Packet，不需要 ATX 接线，但需要电脑主板、固件、网卡与待机供电支持。

## 使用步骤

1. 在电脑 BIOS / UEFI 和操作系统网卡配置中启用所需唤醒能力。
2. 在页面添加设备名称和正确的 MAC 地址。
3. 确认 BliKVM 与电脑之间的网络允许唤醒报文到达。
4. 使用具备电源操作权限的账号点击唤醒，并观察电脑是否真正启动。

“已发送”只证明报文发送成功，不证明目标已经开机。跨子网、无线、完全断电或特定关机状态下可能无法唤醒，应先在同一局域网验证。

WOL 没有可靠的强制关机或复位功能，需要这些操作时使用正确接线的 [ATX 控制](./atx.md)。
