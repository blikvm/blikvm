# 设备时间与 RTC

正确时间影响 HTTPS、双重验证、VPN、升级验证和审计。RTC 在断电期间保持时间，网络校时负责在联网后纠正偏差，两者不能互相替代。

## 检查时间

1. 在设备信息中查看时间相关状态，并与可信时间源比较。
2. 若 2FA 验证码、证书或联网服务异常，先检查设备和管理电脑时间是否正确。
3. 需要管理员诊断时，可在设备终端运行只读命令：

```sh
date
ls -l /dev/rtc*
```

存在 RTC 节点且镜像提供 `hwclock` 时，可先按实际节点读取，例如 `hwclock -r -f /dev/rtc0`。不要假设每个型号都使用同一 I²C 总线、芯片或 `rtc0` 编号。

## 电池与持久校时

按型号要求安装合适电池并注意极性。需要更换电池时先断电，遵守对应硬件指南。没有电池、驱动未识别或设备长期离线，都可能导致时间漂移。

当前指南不要求手工向 I²C `new_device` 写入设备，也不通用地执行 `hwclock -w`。持久校时方式由当前系统镜像管理；先检查服务与硬件识别，再按该镜像说明恢复。

视频分析页面的临时 NTP 服务用于测量环境，不是设置设备日常校时源的按钮，见[延迟测量](../video/latency.md)。
