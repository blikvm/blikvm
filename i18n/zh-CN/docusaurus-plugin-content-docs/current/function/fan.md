# 温度与风扇

设备信息页显示健康状态；有可调风扇能力的设备提供**设置 → 设备与系统 → 风扇**。

## 配置与验证

1. 先检查风扇电气规格、接线及散热器安装，不能仅依据菜单判断已安装风扇。
2. 在风扇页查看并调整温度阈值，确认保存成功。
3. 在正常负载下观察温度和风扇实际行为，确保不会因为过低供电或错误接线停转。
4. 记录环境温度、设备负载和散热条件，再比较调整前后结果。

当前 v4 / H616 适配不开放软件风扇控制入口，即使板上存在连接器，也不能据此假设支持网页调速。阈值控制也不等于任意 PWM 曲线控制。

温度显示单位属于[界面偏好](./interface-preferences.md)与健康显示设置，不会改变硬件温度。若持续过热，应先改善物理散热和供电；不要为了测试风扇而阻挡散热或运行未知压力脚本。
