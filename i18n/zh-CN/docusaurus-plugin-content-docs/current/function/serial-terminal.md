# 被控设备串口终端

串口终端访问串口所连接的设备，不是 BliKVM 自身 shell。需要串口权限及正确的物理电平、线序和端口。

## 配置

1. 按目标设备手册确认 TTL / RS-232 等电气标准，使用匹配的适配器；不要把不同电平接口直接连接。
2. 连接 TX、RX、GND 等必要信号，按硬件指南操作。
3. 管理员进入**设置 → 高级与诊断 → 串口设置**，选择实际端口及匹配波特率。
4. 确认“该串口连接目标设备，而不是 KVM 系统控制台”选项与接线一致，避免误用系统控制台。
5. 打开**串口终端**，观察启动日志，并用无破坏性输入验证。

设备没有列出串口时，先检查适配器、驱动和权限。乱码通常来自波特率或电气配置不匹配；完全无输出时检查接线、目标供电及终端占用。

BliKVM v4 的供电口兼具其自身系统串行控制台用途，具体接法见型号页；它与这里的目标设备串口功能应分开理解。
