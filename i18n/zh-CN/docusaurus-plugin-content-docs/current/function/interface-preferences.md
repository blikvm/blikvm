# 界面偏好

入口：**设置 → 界面偏好**。这里主要调整当前浏览器的使用体验，不等于更改电脑操作系统、USB 功能或其他用户设置。

- **语言**：切换网页语言，不改变被控电脑键盘布局。
- **外观**：按界面选择主题等显示偏好。
- **输入方式**：自动、鼠标或触控。自动按触控能力识别，不单纯以屏幕宽度判断；宽屏仍保留桌面布局。
- **网页标题**：属于设备品牌 / 标题配置，可能需要管理员权限，不应认为所有偏好都只保存在浏览器。
- **告警**：调整当前界面的提示行为，关闭提示并不会消除底层错误。

光标样式入口在**键鼠与 USB → 光标样式**。鼠标绝对 / 相对行为与电脑 USB 功能有关，见[鼠标模式](../peripheral-devices/keyboard-mouse/mouse.md)。

语言、主题或触控偏好可能随浏览器、站点来源或存储清理变化；更换设备地址和端口也可能形成新的浏览器存储范围。恢复出厂不会自动清理管理电脑上的本地偏好。
