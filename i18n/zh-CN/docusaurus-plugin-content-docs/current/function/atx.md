# 被控电脑 ATX 电源控制

控制台工具栏的 ATX 电源操作影响**被控电脑**。BliKVM 自身的重启位于更新与维护，不应混用。

## 接线和验证

1. 按[ATX 配件指南](../accessories/atx-guide.mdx)及主板手册连接电源按钮、复位按钮和指示灯信号。
2. 确认控制的是正确电脑；配合切换器时，先检查当前通道。
3. 具备电源权限的用户可执行普通电源动作；长按强制操作还需要单独的强制电源权限。
4. 先用计划内的普通操作验证，并同时查看电脑画面和电源指示状态。

短按通常模拟机箱电源按钮，实际结果由电脑固件和操作系统电源策略决定；长按可能导致未保存数据丢失，复位也不是正常关机。不要通过重复发送强制动作排查无响应。

如果网页请求成功但电脑无反应，检查线序、极性、接线对象和切换器通道。当前功能以设备能力为准，不要求网页用户手工配置 GPIO。
