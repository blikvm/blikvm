# DDNS 动态域名

入口：**设置 → 远程访问 → DDNS**。DDNS 将变化的 IPv4 / IPv6 地址更新到域名解析，不负责打通 NAT、防火墙或视频中继。

## 配置步骤

1. 先确认网络有可用外连，并拥有域名和相应 DNS 服务权限。
2. 在设备页面启用 DDNS-GO，等待服务正常运行。
3. 打开配置界面，在 DDNS-GO 中选择实际服务商、填写所需凭据和域名，并选择需要的 IPv4 / IPv6 更新策略。
4. 检查更新日志和域名解析结果，再从外部网络访问。
5. 如使用 IPv6，确认客户端也有可达 IPv6，且设备和路由器防火墙允许所需访问。

## 结果判断

域名解析到正确地址，不代表相应端口可入站；内网地址、运营商 NAT 或仅链路本地 IPv6 均不能直接充当公网入口。IPv6 地址变化后，还要考虑 DNS 缓存和实际防火墙规则。

服务已启用但未运行时，先检查组件、上行网络和时间。配置应通过当前服务入口管理，系统更新保留行为以发布说明为准；恢复出厂会清除相应状态。DNS 凭据属于私密数据，分享日志前移除。
