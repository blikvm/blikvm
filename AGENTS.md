# Repository instructions

## GitHub Releases

This repository hosts public downloads and published release notes. The canonical release template, reviewed bodies and finalization checks belong to `blikvm/blikvm-release`; see its `docs/release-notes.md` and `packaging/publish-release.sh`. Do not reintroduce duplicate templates or release-body update workflows here. Preserve tags, assets and publication status unless explicitly authorized; never fabricate validation evidence. Existing website/documentation conventions remain applicable to other tasks.
